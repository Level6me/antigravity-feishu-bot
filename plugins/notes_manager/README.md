# 📝 备忘录与随手记插件 (`notes_manager`)

`notes_manager` 是提供便签随手记、工作备忘、闪念灵感记录与查看管理的飞书机器人扩展插件。

---

## 📌 功能特性

- **快捷记录**：使用 `/note add <内容>` 迅速保存一条灵感便签；
- **交互式列表**：弹出的飞书交互卡片支持清晰分页查看所有已保存的随手记；
- **卡片实时删除**：直接在飞书卡片上点击 **`🗑️ 删除`** 按钮物理清理旧便签并无缝更新卡片。

---

## ⚙️ 指令与使用方法

| 斜杠指令 | 参数 | 描述 | 示例 |
| :--- | :--- | :--- | :--- |
| `/note` | `add <内容>` | 快速添加一条新便签内容 | `/note add 明天上午10点参加周会` |
| `/notes` | 无 | 打开便签与随手记卡片看板 | `/notes` |

---

## 📋 插件配置与清单 (`manifest.json`)

```json
{
  "id": "notes_manager",
  "name": "📝 备忘录与随手记插件",
  "version": "2.0.0",
  "author": "Antigravity",
  "description": "随时快速记录、列出与管理个人的随手记、灵感与工作备忘条目",
  "commands": [
    "/note",
    "/notes"
  ],
  "enabled": true
}
```

---

## 🛠️ 卡片交互回调动作

- `prompt_add_note`: 触发提示输入便签的流程
- `delete_note`: 删除指定索引的随手记条目
