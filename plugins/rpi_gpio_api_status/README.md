# 🍓 树莓派 GPIO 状态灯指示插件 (API 网关独立版 v2.0)

基于 [pi_led_api](https://github.com/Level6me/pi_led_api) 集中式 HTTP 网关控制树莓派红绿黄三色 LED 指示灯，与飞书 Bot 全生命周期联动，并提供精简纯净的飞书交互式控制面板与独立消息配置。

---

## 🎯 核心联动与预设状态

| 状态预设 | 视觉表现 | 触发时机 / 说明 |
| :--- | :--- | :--- |
| **🟡 思考中** | 黄灯常亮 (`thinking`) | AI 开始推理思考时自动触发 / 按钮切换 |
| **✨ 正弦呼吸** | 黄灯正弦平滑呼吸 (`breathing`) | AI 正在调用外部工具执行时自动触发 / 按钮切换 |
| **🟢 成功完成** | 绿灯常亮 300s 后渐灭 (`success`) | AI 任务成功响应后自动触发 / 按钮切换 |
| **🔴 异常报错** | 红灯常亮 (`error`) | 执行出错或被 `/stop` 强停时自动触发 / 按钮切换 |
| **⏹️ 熄灭全灯** | 全部熄灭 (`off`) | 一键关闭所有通道 |

---

## 💬 飞书交互指令与操作

| 指令 | 说明 |
| :--- | :--- |
| `/led` 或 `/light` | 弹出飞书精简控制面板卡片（支持点击按钮即时控制） |
| `/led test` | 快速测试当前网关连通性与网络 RTT 延迟 |
| `/led config` | 进入交互式配置中心（点击按钮即可通过聊天消息回复新的 URL 或 Token） |
| `/led thinking` | 切换为【思考中】(常亮黄灯) |
| `/led breathing` | 切换为【任务执行中】(正弦呼吸黄灯) |
| `/led success` | 切换为【任务完成】(常亮绿灯 300s) |
| `/led error` | 切换为【系统异常】(常亮红灯) |
| `/led startup` | 触发【开机自检】(绿灯连闪 5 次) |
| `/led off` | 熄灭所有通道 |

---

## 🎛️ 飞书卡片可视化操作

1. **🎯 快速切换系统预设**：直接点击卡片上的【🟡 思考中】、【✨ 正弦呼吸】、【🟢 成功完成】、【🔴 异常报错】、【⏹️ 熄灭全灯】。
2. **🌐 修改网关 URL**：点击按钮后，机器人将在聊天中发送独立提示，直接回复新的网关地址即可自动保存并即时测试。
3. **🔑 修改 API Token**：点击按钮后，机器人发送独立提示，直接回复 Token 即可完成绑定。
4. **🔌 测试连通性**：点击按钮即时测量 RTT 响应延迟（ms）。
